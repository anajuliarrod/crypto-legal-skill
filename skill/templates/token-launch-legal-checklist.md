# Token Launch — Legal Readiness Checklist

> **Draft / working checklist for counsel to finalize. Not legal advice.** Tailor to your jurisdictions and token. Items marked 🛑 require a licensed attorney; ⚠️ are fast-moving — re-verify against [../sources.md](../sources.md).

## 0. Context locked
- [ ] Issuer jurisdiction decided
- [ ] DevCo jurisdiction decided & separated from issuer
- [ ] Target user markets listed
- [ ] **U.S. persons in scope? yes/no** (drives everything)
- [ ] Token type fixed (governance / utility / stablecoin / NFT)

## 1. Entity & structure ([../entity-structuring.md](../entity-structuring.md))
- [ ] Issuer entity formed (Foundation / DAO LLC / SPV)
- [ ] DevCo formed; IP assigned to the right entity
- [ ] Intercompany agreements (DevCo ↔ Foundation) drafted 🛑
- [ ] Beneficial-ownership / KYB records ready for banking
- [ ] Economic-substance plan per entity ⚠️

## 2. Securities posture ([../token-launch.md](../token-launch.md))
- [ ] Howey analysis documented (US) 🛑 #us-securities-sec-cftc
- [ ] Exemption selected (Reg D / Reg S) **or** US geoblocked
- [ ] Decentralization posture documented (if relied on) 🛑
- [ ] MiCA whitepaper prepared if offering into EU ⚠️ #eu-mica
- [ ] Per-target-market securities read 🛑

## 3. Distribution mechanics
- [ ] Mechanism chosen (private SAFT / public / airdrop / points)
- [ ] Investor docs drafted (SAFT / SAFE + token warrant) 🛑
- [ ] Vesting/lockups documented (team + investors)
- [ ] Airdrop: anti-sybil + geoblocking + recipient tax note ⚠️
- [ ] Tokenomics allocation legally reviewed

## 4. Compliance program ([../compliance-ops.md](../compliance-ops.md))
- [ ] Sanctions/OFAC screening on sale & claim flows 🛑 #us-aml-fincen-ofac
- [ ] Money-transmission / MSB / MTL determination 🛑
- [ ] KYC where required by exemption/activity
- [ ] Geoblocking policy written **and technically enforced** ([geoblocking-policy.md](geoblocking-policy.md))

## 5. Public docs ([terms-of-service-skeleton.md](terms-of-service-skeleton.md), [risk-disclaimer.md](risk-disclaimer.md))
- [ ] Terms of Service published
- [ ] Privacy Policy published (GDPR if EU/UK users) ⚠️
- [ ] Risk disclaimers on token/trading/yield surfaces
- [ ] Marketing reviewed: no price-appreciation promises; promotions rules (UK/EU) ⚠️

## 6. Tax 🛑
- [ ] Issuer tax structure reviewed
- [ ] Founder personal tax (CFC/PFIC/PE/exit) reviewed **before** allocations
- [ ] Recipient tax disclosure for airdrops/comp

## 7. Post-launch
- [ ] Listing/market-maker agreements reviewed (no wash trading / manipulation) 🛑
- [ ] Ongoing sanctions screening live
- [ ] Governance → legal authority mapping (if DAO) ([../dao-governance.md](../dao-governance.md))
- [ ] Records retained; compliance officer named (if program required)

---
**Counsel sign-off before launch:** securities opinion ☐ · structure ☐ · tax ☐ · sale docs ☐
